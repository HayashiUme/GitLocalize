# Documentazione

GitLocalize è una piattaforma di traduzione collaborativa che funziona interamente su GitHub: senza server né database, il repository è il backend.

1. **Ottieni un token di accesso** — Fine-grained, limitato al tuo repository, con Contents in lettura e scrittura.
2. **Distribuisci la tua copia** — Crea il repository dal template ed esegui scripts/setup-repo.sh.
3. **Traduci nell’editor** — Apri l’editor pubblicato, incolla il token e fai commit con la tua identità.

Le guide complete sono in inglese per ora; i collegamenti sono qui sotto.
