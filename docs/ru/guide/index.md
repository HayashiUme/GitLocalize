# Документация

GitLocalize — платформа для совместного перевода, работающая целиком на GitHub: без сервера и базы данных, репозиторий сам является бэкендом.

1. **Получите персональный токен** — Fine-grained, ограниченный вашим репозиторием, с правом чтения и записи Contents.
2. **Разверните свою копию** — Создайте репозиторий из шаблона и запустите scripts/setup-repo.sh.
3. **Переводите в редакторе** — Откройте опубликованный редактор, вставьте токен и коммитьте от своего имени.

Полные руководства пока на английском; ссылки ниже.
