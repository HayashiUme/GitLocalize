# Documentation

GitLocalize is a translation collaboration platform that runs entirely on GitHub: no server, no database, the repository is the backend.

1. **Get a personal access token** — Fine-grained, scoped to your repository, with Contents read and write.
2. **Deploy your own copy** — Use this template, run scripts/setup-repo.sh, done.
3. **Translate in the editor** — Open the published editor, paste the token, commit as yourself.

The full guides are linked below. They are currently written in English; translations are being added language by language.
