# Dokumentacja

GitLocalize to platforma do współtworzenia tłumaczeń działająca w całości na GitHubie: bez serwera i bazy danych — samą repozytorium jest backendem.

1. **Uzyskaj osobisty token dostępu** — Fine-grained, ograniczony do twojego repozytorium, z odczytem i zapisem Contents.
2. **Wdróż własną kopię** — Utwórz repozytorium z szablonu i uruchom scripts/setup-repo.sh.
3. **Tłumacz w edytorze** — Otwórz opublikowany edytor, wklej token i commituj pod własnym nazwiskiem.

Pełne przewodniki są na razie po angielsku; linki poniżej.

- [Uzyskanie tokenu (ang.)](/guide/token.md)
