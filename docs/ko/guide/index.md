# 문서

GitLocalize는 GitHub 위에서만 동작하는 번역 협업 플랫폼입니다. 서버도 데이터베이스도 없으며 저장소 자체가 백엔드입니다.

1. **개인 액세스 토큰 발급** — 이 저장소로 한정된 fine-grained 토큰에 Contents 읽기/쓰기를 허용합니다.
2. **자신만의 GitLocalize 배포** — 템플릿으로 저장소를 만들고 scripts/setup-repo.sh를 실행하세요.
3. **편집기에서 번역** — 공개된 편집기를 열고 토큰을 붙여넣어 본인 명의로 커밋합니다.

전체 가이드는 현재 영어로 제공됩니다. 아래 링크를 참고하세요.

- [토큰 받기(영어)](/guide/token.md)
- [배포 가이드(영어)](/guide/deploy.md)
