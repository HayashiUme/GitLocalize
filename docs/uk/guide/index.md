# Документація

GitLocalize — платформа для спільного перекладу, що працює повністю на GitHub: без сервера й бази даних, сам репозиторій є бекендом.

1. **Отримайте персональний токен** — Fine-grained, обмежений вашим репозиторієм, з правом читання й запису Contents.
2. **Розгорніть власну копію** — Створіть репозиторій із шаблону та запустіть scripts/setup-repo.sh.
3. **Перекладайте в редакторі** — Відкрийте опублікований редактор, вставте токен і комітьте від свого імені.

Повні посібники поки що англійською; посилання нижче.
