# Documentation

GitLocalize est une plateforme de traduction collaborative qui fonctionne entièrement sur GitHub : sans serveur ni base de données, le dépôt est le backend.

1. **Obtenez un jeton d’accès** — Fine-grained, limité à votre dépôt, avec Contents en lecture et écriture.
2. **Déployez votre propre copie** — Créez le dépôt depuis le modèle puis lancez scripts/setup-repo.sh.
3. **Traduisez dans l’éditeur** — Ouvrez l’éditeur publié, collez le jeton et commitez en votre nom.

Les guides complets sont en anglais pour le moment ; les liens sont ci-dessous.

- [Obtenir un jeton (anglais)](/guide/token.md)
- [Guide de déploiement (anglais)](/guide/deploy.md)
