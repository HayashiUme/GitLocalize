# Documentación

GitLocalize es una plataforma de traducción colaborativa que funciona por completo en GitHub: sin servidores ni bases de datos, el repositorio es el backend.

1. **Obtén un token de acceso** — Fine-grained, limitado a tu repositorio, con Contents de lectura y escritura.
2. **Despliega tu propia copia** — Crea el repositorio desde la plantilla y ejecuta scripts/setup-repo.sh.
3. **Traduce en el editor** — Abre el editor publicado, pega el token y haz commits con tu identidad.

Las guías completas están en inglés por ahora; los enlaces están abajo.
