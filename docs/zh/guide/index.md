# 文档

GitLocalize 是一个完全运行在 GitHub 上的翻译协作平台：没有服务器、没有数据库，仓库本身就是后端。

1. **获取个人访问令牌** — 细粒度令牌，仅限本仓库，授予 Contents 读写权限。
2. **部署你自己的 GitLocalize** — 使用模板创建仓库，运行 scripts/setup-repo.sh 即可。
3. **在编辑器中翻译** — 打开在线编辑器，粘贴令牌，以你自己的身份提交。
