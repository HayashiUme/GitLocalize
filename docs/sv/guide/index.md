# Dokumentation

GitLocalize är en samarbetsplattform för översättning som körs helt på GitHub: ingen server, ingen databas — själva repot är backend.

1. **Skaffa en personlig åtkomsttoken** — Fine-grained, begränsad till ditt repo, med läs- och skrivbehörighet för Contents.
2. **Distribuera din egen kopia** — Skapa repot från mallen och kör scripts/setup-repo.sh.
3. **Översätt i editorn** — Öppna den publicerade editorn, klistra in token och committa i ditt eget namn.

De fullständiga guiderna är för närvarande på engelska; länkar nedan.

- [Hämta token (engelska)](/guide/token.md)
- [Distributionsguide (engelska)](/guide/deploy.md)
