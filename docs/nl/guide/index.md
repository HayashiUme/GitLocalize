# Documentatie

GitLocalize is een vertaalsamenwerkingsplatform dat volledig op GitHub draait: geen server, geen database — de repository is zelf de backend.

1. **Vraag een personal access token aan** — Fine-grained, beperkt tot je repository, met Contents lezen en schrijven.
2. **Zet je eigen kopie neer** — Maak de repository vanuit de template en draai scripts/setup-repo.sh.
3. **Vertaal in de editor** — Open de gepubliceerde editor, plak de token en commit onder je eigen naam.

De volledige gidsen zijn voorlopig Engelstalig; de links staan hieronder.

- [Token aanvragen (Engels)](/guide/token.md)
