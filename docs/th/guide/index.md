# เอกสาร

GitLocalize คือแพลตฟอร์มการแปลแบบร่วมมือกันที่ทำงานบน GitHub ทั้งหมด: ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล — ตัวรีโพสิทอรีนั่นเองคือแบ็กเอนด์

1. **ขอรับ personal access token** — แบบ fine-grained จำกัดเฉพาะรีโพสิทอรีของคุณ พร้อมสิทธิ์อ่าน/เขียน Contents
2. **ติดตั้งสำเนาของคุณเอง** — สร้างรีโพสิทอรีจาก template แล้วรัน scripts/setup-repo.sh
3. **แปลในตัวแก้ไข** — เปิดตัวแก้ไขที่เผยแพร่ วาง token แล้วคอมมิตในนามของคุณ

คู่มือฉบับเต็มเป็นภาษาอังกฤษในตอนนี้; ลิงก์อยู่ด้านล่าง

- [การขอรับ token (อังกฤษ)](/guide/token.md)
- [คู่มือการติดตั้ง (อังกฤษ)](/guide/deploy.md)
