# दस्तावेज़

GitLocalize एक ऐसा अनुवाद सहयोग मंच है जो पूरी तरह GitHub पर चलता है: कोई सर्वर नहीं, कोई डेटाबेस नहीं — रिपॉज़िटरी ही बैकएंड है।

1. **पर्सनल एक्सेस टोकन लें** — फ़ाइन-ग्रेन्यूल्ड, केवल अपने रिपॉज़िटरी के लिए, Contents पढ़ने/लिखने के साथ।
2. **अपनी कॉपी तैनात करें** — टेम्पलेट से रिपॉज़िटरी बनाएँ और scripts/setup-repo.sh चलाएँ।
3. **एडिटर में अनुवाद करें** — प्रकाशित एडिटर खोलें, टोकन चिपकाएँ, और अपने नाम से कमिट करें।

पूर्ण गाइड अभी अंग्रेज़ी में हैं; लिंक नीचे हैं।
