# Dokumentation

GitLocalize ist eine Übersetzungsplattform, die komplett auf GitHub läuft: ohne Server, ohne Datenbank – das Repository ist das Backend.

1. **Personal Access Token holen** — Fine-grained, auf dein Repository beschränkt, mit Contents-Lese-/Schreibzugriff.
2. **Eigene Kopie aufsetzen** — Repository aus der Vorlage erstellen und scripts/setup-repo.sh ausführen.
3. **Im Editor übersetzen** — Veröffentlichten Editor öffnen, Token einfügen, unter eigenem Namen committen.

Die vollständigen Anleitungen sind derzeit englischsprachig; die Links finden Sie unten.
