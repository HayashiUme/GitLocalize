# 文件

GitLocalize 是一個完全執行在 GitHub 上的翻譯協作平台：沒有伺服器、沒有資料庫，儲存庫本身就是後端。

1. **取得個人存取權杖** — 精細權杖，僅限本儲存庫，授予 Contents 讀寫權限。
2. **部署你自己的 GitLocalize** — 使用範本建立儲存庫，執行 scripts/setup-repo.sh 即可。
3. **在編輯器中翻譯** — 開啟線上編輯器，貼上權杖，以你自己的身分提交。
