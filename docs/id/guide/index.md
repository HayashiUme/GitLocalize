# Dokumentasi

GitLocalize adalah platform kolaborasi terjemahan yang berjalan sepenuhnya di GitHub: tanpa server, tanpa basis data — repositorinya adalah backend-nya.

1. **Dapatkan token akses pribadi** — Fine-grained, terbatas pada repositori Anda, dengan izin baca-tulis Contents.
2. **Sebar salinan Anda sendiri** — Buat repositori dari template lalu jalankan scripts/setup-repo.sh.
3. **Terjemahkan di editor** — Buka editor yang dipublikasikan, tempel token, dan commit dengan identitas Anda.

Panduan lengkap saat ini dalam bahasa Inggris; tautan di bawah.
