# Belgeler

GitLocalize, tamamen GitHub üzerinde çalışan bir çeviri işbirliği platformudur: sunucu yok, veritabanı yok — depo kendisi arka uçtur.

1. **Kişisel erişim tokenı alın** — Fine-grained, yalnızca deponuz için, Contents okuma-yazma yetkisiyle.
2. **Kendi kopyanızı kurun** — Şablondan depo oluşturun ve scripts/setup-repo.sh dosyasını çalıştırın.
3. **Editörde çevirin** — Yayınlanan editörü açın, tokenı yapıştırın ve kendi adınıza commit atın.

Eksiksiz kılavuzlar şimdilik İngilizcedir; bağlantılar aşağıda.

- [Token alma (İngilizce)](/guide/token.md)
- [Dağıtım kılavuzu (İngilizce)](/guide/deploy.md)
